# LaserBox 3D

Projetista web de caixas para corte a laser em MDF.

## Primeira versão
- Ajuste de largura, profundidade, altura e espessura do MDF.
- Visualização 3D com rotação, zoom e grade.
- Controles de quantidade e largura dos dedos, além de folga/kerf.
- Alternância entre distribuição automática e modo personalizado.
- Exportação de desenho SVG em milímetros.

## Publicar com GitHub Pages
No repositório, abra **Settings → Pages**, escolha **Deploy from a branch**, selecione **main** e a pasta **/(root)** e salve. O site ficará disponível em:
https://adonias864.github.io/laserbox-3d/

## Observação importante
Esta é uma versão inicial de interface e prototipagem. A geração SVG ainda precisa de validação e evolução da geometria de encaixe complementar entre cada par de peças antes de ser usada como arquivo final de produção. Faça sempre um teste em retalho e confira as dimensões no software de corte.
